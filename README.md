# LandslideObsRobust

Supporting records for **Robustness Remains Regime-Dependent in Event-Aligned Multimodal Landslide Segmentation under Missing Satellite Observations**.

This repository currently provides a concise audit summary extracted from retained experimental records. The full implementation, training and evaluation scripts, split files, and evaluation-mask generation code will be made publicly available here upon publication of the article.

- `audit_summary.json`: selected audit outcomes, key result values, and source-record checksums.
- `SHA256SUMS`: checksum of the audit summary.
